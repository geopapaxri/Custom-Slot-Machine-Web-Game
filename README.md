# Retro Slot Machine Web Game 🎰

🎮 **[Play the game live here!](https://geopapaxri.github.io/Custom-Slot-Machine-Web-Game/slot-machine/)**

## Overview
I built this custom, retro-themed slot machine web game **just for fun** in my free time! It was developed entirely using HTML, CSS, and vanilla JavaScript as a personal challenge to experiment with front-end development, UI design, and game logic without relying on external game engines or heavy frameworks.

## Features
* **Responsive UI/UX:** The interface is built with responsive design in mind, ensuring playability across both desktop and mobile devices. It features dynamic styling and animations using CSS grid and keyframes.
* **Game Logic & Probability:** Implements custom logic for symbol weighting, calculating probabilities, and determining winning combinations based on a predefined paytable.
* **Bonus Mechanics:** Includes advanced slot machine mechanics such as scatter symbols, free spin rounds, retriggers, and progressive multipliers during bonus phases.
* **Audio Engine:** Utilizes the Web Audio API to dynamically generate retro 8-bit sound effects (e.g., spin, pop, win sounds) without requiring external audio files for sound effects.
* **State Management:** Handles game states seamlessly, tracking balance, current bets, wins, and active bonus rounds while providing user feedback through a custom pop-up system.

## Technologies Used
* **HTML5**
* **CSS3** (Grid, Flexbox, Animations, Responsive Design)
* **Vanilla JavaScript** (Game Loop, Web Audio API, DOM Manipulation)
